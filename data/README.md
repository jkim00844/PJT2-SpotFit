# SpotFit 원천 데이터 (2025년분)

- **수집일**: 2026-10-10
- **수집 범위**: 2025년만. 분기 데이터는 2025Q1~Q4(`20251`~`20254`), 시점 데이터는 2025-12-31 기준입니다.
- **출처 상세**: [../RAW_DATA_SOURCES.md](../RAW_DATA_SOURCES.md)
- **파일별 크기·행 수·기간**: [raw/MANIFEST.csv](raw/MANIFEST.csv) (수집 스크립트가 자동으로 만듭니다)

## 받는 방법

**git clone**: 저장소에 `소상공인_상가정보_서울.csv`(278MB)를 뺀 나머지 데이터가 모두 들어 있습니다. GitHub는 100MB가 넘는 파일을 받지 않기 때문입니다. 소상공인 파일은 clone한 뒤 아래 명령으로 받으세요.

```bash
python scripts/fetch_raw_2025.py --only sbiz
```

**공유 zip 사용**: `SpotFit_raw_2025.zip`(소상공인 파일 포함 전체)을 `PJT2-SpotFit/` 폴더에서 압축 해제하면 `data/raw/`가 생깁니다.

**직접 다시 받기**: Python 3.8 이상이면 추가 설치 없이 실행됩니다 (Windows·macOS 공통).

```bash
cd PJT2-SpotFit
python scripts/fetch_raw_2025.py                    # 전체 (네이버는 API 키가 있을 때만)
python scripts/fetch_raw_2025.py --only trade sbiz  # 일부만
python scripts/fetch_raw_2025.py --force            # 이미 받은 파일도 다시 받기
```

중간에 실패한 항목이 있으면 마지막 줄에 다시 실행할 명령어가 출력됩니다. 이미 받은 파일은 건너뜁니다.

## 주의할 점

- **인코딩**: 모든 CSV는 UTF-8(BOM)입니다. pandas에서는 `pd.read_csv(path, encoding="utf-8-sig")`로 읽고, Excel에서 바로 열어도 한글이 깨지지 않습니다.
- **행정동 이름의 `?`**: `종로1?2?3?4가동`, `상계3?4동`처럼 가운뎃점(·)이 `?`로 들어간 동이 있습니다. 서울시가 배포하는 원본이 이 상태라서 고치지 않았습니다. 테이블을 합칠 때는 이름 대신 `행정동_코드`를 기준으로 쓰세요.
- **행 수가 1,700보다 적은 파일**: 아파트(1,696행), 직장인구(1,656행)는 원본에 일부 동·분기 행이 없는 경우입니다. 수집 중에 빠진 것이 아닙니다.
- **소상공인 상가정보**: 분기별이 아니라 2025-12-31 시점의 스냅샷 하나입니다.
- **네이버 검색지수**: 조회 기간(2025-01~12) 안에서 최댓값을 100으로 놓은 상대값입니다. 예전에 2021~2026 기간으로 받은 값과 숫자를 직접 비교할 수 없습니다. 검색량이 적어 값이 비어 있는 달은 0.0으로 채웠습니다 (25개 구 키워드 중 `명일동 학원`, `수유시장 장보기`, `중계동 은행사거리 학원`, `망원시장 장보기`, `길상사 나들이`, `성신여대 로데오`, `중랑천 장미축제` 7개에서 총 55개월). 다시 받으려면 네이버 API 키가 필요합니다 (`config/naver_api_key.json` 또는 `--naver-key` 옵션).

## 이 패키지에 없는 데이터

- **서울 체류인구(250m, 내국인, `OA-22892`)**: 2025년분은 월 단위 zip으로만 제공되고 한 달에 약 450MB(1년이면 약 5.5GB)라서 뺐습니다. 필요하면 월을 지정해 받을 수 있습니다: `python scripts/fetch_raw_2025.py --stay 2512` (2025년 12월, 이미 받은 파일은 건너뜀).
- **통계청 MDIS 가계금융복지조사 2025**: 로그인과 이용 신청이 필요해서 자동 수집이 안 됩니다. [MDIS](https://mdis.kostat.go.kr)에서 2025년 가구마스터·가구원 파일을 직접 받아 주세요.
